## Decisions that matter

- Verify the Arabic title convention, current category price ranges, distinct personal/commercial price fields, cover dimensions and minimum real gallery-image count from these sources. Check whether the final delivery belongs in mobile, web or another available category; desktop-only software does not become a mobile application because it uses Flutter.
- Assign the user's general price to the appropriate license and state the interpretation. A POS used for a business needs particular attention to commercial-license rights. Keep an unspecified secondary price unset or explicitly proposed, rather than presenting it as the user's choice. Do not map Envato's Regular/Extended rights onto these licenses.
- Use Picalica's own commission and price-entry model. Do not subtract Envato buyer fees. Choose non-exclusive for a continuing multi-marketplace plan unless the user has chosen otherwise and the plan is compatible with current terms.
- Check activation-code and editable/ready-to-use requirements early. In the original Sanad preparation, official guidance made activation codes a publication blocker. Reverify the rule and actual code path for the current run. Supplying a manual key or merely removing a signing tool does not resolve a prohibition on requiring activation codes.
- An Arabic HTML guide should explain building/running, first use, daily workflows, customization, backup, limitations and credits, with genuine visual instruction when required. An existing English CodeCanyon guide alone is not an Arabic buyer guide.
- Verify current support entitlements instead of importing a six-month CodeCanyon promise. Use platform messaging for the prepared support copy. If terms are inaccessible, label external-contact recommendations as editorial choices, not verified prohibitions.
- Capture actual product screens with synthetic data. A cover design, repeated marketing cards or a documentation preview does not satisfy a required gallery of product screenshots.

## Final checks

The product ZIP must match the demonstrated release, include the Arabic guide and notices, and be usable under the purchased license. List missing seller identity, preview URL, category confirmation, rights and release acceptance separately. Keep a clear candidate status whenever a required activation change, image set or usable release is still missing.
